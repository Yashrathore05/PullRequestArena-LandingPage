What Makes It Different

Instead of only testing code generation, PullRequest Arena tests whether an agent can behave like a senior reviewer: identify subtle failure modes, resist misleading cues, and take the right review action.

Security Bugs

Detect SQL injection patterns, auth bypasses, and unsafe code paths.

Performance Regressions

Spot hidden complexity increases and suspicious runtime behavior changes.

Concurrency Issues

Catch race conditions and thread-safety flaws in realistic diffs.

Adversarial Logic

Handle deceptive PR titles and social-context traps without false approvals.

Evaluation Protocol

1. Observe PR Context

The agent receives structured inputs including `code_diff`, repository context, test results, CI logs, and prior comments.

2. Choose an Action

Actions are discrete: `approve`, `request_changes`, `comment`, `suggest_fix`, or `submit_patch`.

3. Deterministic Grading

The environment checks logic and patch correctness and assigns normalized rewards from `0.01` to `0.99`.
